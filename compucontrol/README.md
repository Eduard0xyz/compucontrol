# CompuControl · Gestión de equipos y sistemas de cómputo

Proyecto del curso Soporte Operativo de Hardware y Software (React + Vite).

## Ejecutar en tu computadora (Windows)
1. Instala Node.js (versión LTS) desde https://nodejs.org
2. Abre la carpeta en una terminal y ejecuta:
   npm install
   npm run dev
3. Abre el enlace que aparece (http://localhost:5173)

## Publicar en Vercel
1. Sube esta carpeta a un repositorio de GitHub.
2. En https://vercel.com entra con GitHub, pulsa "Add New > Project" y elige el repositorio.
3. Vercel detecta Vite solo. Pulsa "Deploy" y te da el link.
